# Calculator Web Application

A simple yet functional web-based calculator built using HTML, CSS, and JavaScript. This calculator allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features

- **Basic Arithmetic Operations**: Perform addition, subtraction, multiplication, and division.
- **Responsive Design**: The layout adjusts to various screen sizes for optimal use on both desktop and mobile devices.
- **Clear & Reset Functions**: Reset the current input and clear the entire calculation.
